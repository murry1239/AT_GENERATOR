# 변경 이력

## Alpha 0.9

- 변분기 Alpha 0.4의 schema_version 2 `.bdsg`를 직접 읽는 2단계 흐름을 구현했습니다.
- Alpha 0.7·0.8의 5열 가로 대비표, 변경 표시, 사유 공란, 수동 검토·완료 알림을 이어받았습니다.
- Word 변경기록 승인·거부 및 페이지 재계산을 제거했습니다.
- 편집 가능한 텍스트·병합/중첩표와 패키지 이미지 출력 방식을 제공합니다.
- 검토 내용을 패키지 해시에 연결해 저장·복원합니다.
- 캡처 실패·복합 표 대체 내역을 문서 확인사항으로 보존합니다.
- 원본 해시·패키지 경로·변경 ID 검증과 취소 시 기존 출력 보존을 추가했습니다.
- 업무 문서를 포함하지 않는 배포 ZIP과 GitHub 업로드 BAT/PowerShell을 추가했습니다.

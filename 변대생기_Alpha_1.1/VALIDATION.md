# Alpha 1.1 검증 · 2026-10-06

- Python 3.11에서 회귀시험 31개(기존 16개와 매칭 검토 15개)를 통과했습니다. 기본 입력은 변분기 1.1의 호환 패키지이며, 명시적 1.1 version과 기존 1.0·0.5·0.4 패키지를 읽고 DOCX를 생성했습니다.
- 범위 메타데이터의 `paragraph_end < front_matter_end`를 가진 0.5·1.0 패키지에 변분기 1.1 재분석 경고를 표시하고 최종 DOCX 확인사항에 기록했습니다. 종료 위치가 목차 종료와 같거나 더 뒤인 경우에는 이 경고가 발생하지 않았습니다. 기존 항목 수는 유지하며 누락 항목을 만들어내지 않습니다.
- 병합·중첩표, 삽입 이미지 관계, 각주 텍스트 보존, 변경 표시, 검토 JSON·병합·제외, 취소 시 기존 출력 보존, 경로·해시·범위 정책 검증을 확인했습니다.
- 뒤바뀐 전후 매칭을 수정하고 v2 검토 JSON 저장·복원 후 DOCX의 새 대응 관계와 변경 표시를 확인했습니다. 일대다·다대일 연결, 추가/삭제 분리·재연결, 수정 후 병합·제외, 기존 v1 검토 이관도 검증했습니다.
- 매칭 수정 시 원문 ID의 누락·중복·방향 오류·알 수 없는 ID·빈 행·잘못된 검토 형식을 거부하고, 실패·취소 시 기존 검토와 출력 파일을 보존합니다. 패키지 해시가 다른 검토 파일을 거부하고 원본 .bdsg 바이트가 그대로인 것도 확인했습니다.
- 새 대응 관계에서 병합·중첩표, 원본 표의 삽입 그림, 이미지 방식의 좌우별 원본 이미지가 보존되는 것을 확인했습니다. 미리보기는 가상 화면 객체로 검사하여 수정한 후측 원문이 보이고 원래 잘못 연결된 후측 내용이 나타나지 않는 것을 확인했습니다.
- 제공된 실제 범위 재분석 패키지를 읽어 앞부분 4개와 본문 209개, 총 213개 항목을 확인했습니다. 제공된 기존 0.4·0.5·1.0 패키지도 읽고 본문 누락 가능성이 있는 0.5·1.0 범위에서 재분석 안내를 확인했습니다.
- 변분기 1.1의 일반 생성 경로에서 만든 합성 패키지를 전달받아 DOCX를 생성했습니다. 앞부분 병합·중첩표와 본문을 포함하고 목차·별첨을 제외했습니다. Word 페이지 계산은 모의 객체, 이미지는 텍스트 대체 경로로 검증했습니다.
- 두 폴더의 Windows PowerShell 5 업로드 준비를 확인했습니다. 변분기 24개와 변대생기 16개 소스, 통합 ZIP만 준비하며 업무 자료는 포함하지 않습니다. ZIP의 파일 목록·무결성·소스 바이트 일치를 확인했습니다.
- 이번 회귀시험은 생성한 DOCX 구조·내용 및 화면 처리의 가상 객체를 검사한 기록입니다. 실제 새 GUI의 시각 검수나 Word 렌더링 기록은 아닙니다. 실제 Word 렌더링은 아래 이전 버전 검증과 구분합니다.

## Alpha 1.0 검증 · 2026-10-02

- 지원하는 Python 3.11에서 회귀시험 13개를 통과했습니다. 기본 입력인 변분기 1.0, 이전 0.5·0.4 패키지 호환, 병합·중첩표, 그림·각주 보존, 검토 저장, 취소 및 입력 검증을 포함합니다.
- Alpha 1.0 변분기가 합성 전후 DOCX에서 생성한 .bdsg를 읽어 최종 DOCX를 생성했습니다. 앞부분의 병합·중첩표와 본문 변경 2개를 포함하고 목차·별첨 변경은 제외하는 연계 검증을 통과했습니다. 페이지 조회는 모의 객체, 이미지는 텍스트 대체 경로로 확인했습니다.
- Windows PowerShell 5에서 두 폴더의 업로드 준비가 성공했습니다. 명시된 소스 38개와 통합 ZIP만 스테이징되는 것을 확인했습니다.
- 이전 0.10의 생성 방식과 레이아웃을 유지한 버전·배포 정리입니다. 실제 Word 렌더링 기록은 아래 이전 버전의 검증과 구분합니다.

## Alpha 0.10 검증 · 2026-10-01

- 회귀시험 12개 통과: 원문/병합·중첩표, 이미지 대체, 검토 병합/제외/저장, 경로/해시/ID 검증, 취소 시 출력 보존, 각주 처리, 이전 0.4 패키지 안내 및 새 비교 정책 검증.
- 변분기 0.5에서 실제 생성한 schema_version 3 .bdsg를 읽어 대비표 DOCX를 생성했습니다. 앞부분 양식 표와 본문 변경 2개가 포함되며 목차/별첨 변경은 제외됩니다.
- 앞부분 표의 병합과 중첩표가 최종 문서 구조에서 보존되는 것을 확인했습니다. 연계 시험의 페이지 조회/이미지 캡처는 모의 처리하였으므로 실제 페이지와 이미지 캡처 품질 검증과 구분해야 합니다.
- 이전 버전의 본문 생성 기능을 유지합니다. 새 비교 범위는 변분기에서 결정하며 기존 0.4 패키지만으로 누락된 앞부분 변경을 복원하지 않습니다.
- 합성 대비표를 실제 Microsoft Word에서 열어 PDF 1쪽으로 변환하고 시각 확인했습니다. 앞부분 표와 본문 행의 배치 및 변경 표시를 확인했습니다.

# 변경 이력

## Alpha 1.1 · 2026-10-06

- 변분기 Alpha 1.1의 schema_version 3 입력과 1.0 version을 사용하는 호환 패키지 지원
- 기존 Alpha 0.4·0.5·1.0 패키지 지원 유지
- 목차 종료보다 분석 범위가 먼저 끝난 패키지에 본문 누락 가능성과 변분기 1.1 재분석 안내 추가
- 재분석 안내를 읽기 화면·확인사항 미리보기·최종 DOCX에 기록
- 기존 대비표 생성·검토·서식 기능을 유지하고 두 폴더 통합 배포 버전을 1.1로 갱신
- 전후 매칭 확인·수정 화면 추가: 잘못된 연결 해제·재연결, 추가/삭제 분리, 일대다·다대일 대응, 출력 행 순서 조정
- 원본 .bdsg를 보존하고 전후 대응 관계를 별도 bdsg-review-v2 검토 JSON에 저장; 기존 v1 검토 불러오기 유지
- 양쪽 원문 각각의 누락·중복을 검사하고 수정한 원문 블록·표·이미지로 최종 DOCX 생성
- 저장하지 않은 검토가 있을 때 종료·패키지/검토 전환 안내 추가

## Alpha 1.0 · 2026-10-02

- 변분기 Alpha 1.0의 schema_version 3 패키지 입력을 지원
- Alpha 0.5·0.4 패키지 호환과 이전 0.4의 앞부분 재분석 안내 유지
- Alpha 0.10의 5열 대비표, 문서 앞부분 표·본문 출력, 목차·별첨·부록 제외 정책 유지
- 변분기와 변대생기를 각각 한 폴더에 둔 통합 배포 및 GitHub 업로드 흐름으로 정리
- 처음 설치 후에는 RUN.bat만 실행하는 사용 안내 추가

## Alpha 0.10 · 2026-10-01

- 변분기 Alpha 0.5의 schema_version 3과 새 비교 정책을 지원
- 문서 앞부분의 양식 표·문단을 본문과 같은 대비표에 출력
- 기존 Alpha 0.4 패키지 호환 유지 및 앞부분 포함을 위한 재분석 안내
- 새 패키지의 비교 정책 검증 추가
- 병합·중첩표 보존 및 목차·별첨 제외 연계 검증; 회귀시험 12개 통과
- 새 배포 폴더와 codex/byeondaesaenggi-alpha-0.10 업로드 브랜치 제공

## Alpha 0.9

- 변분기 Alpha 0.4의 schema_version 2 `.bdsg`를 직접 읽는 2단계 흐름을 구현했습니다.
- Alpha 0.7·0.8의 5열 가로 대비표, 변경 표시, 사유 공란, 수동 검토·완료 알림을 이어받았습니다.
- Word 변경기록 승인·거부 및 페이지 재계산을 제거했습니다.
- 편집 가능한 텍스트·병합/중첩표와 패키지 이미지 출력 방식을 제공합니다.
- 검토 내용을 패키지 해시에 연결해 저장·복원합니다.
- 캡처 실패·복합 표 대체 내역을 문서 확인사항으로 보존합니다.
- 원본 해시·패키지 경로·변경 ID 검증과 취소 시 기존 출력 보존을 추가했습니다.
- 업무 문서를 포함하지 않는 배포 ZIP과 GitHub 업로드 BAT/PowerShell을 추가했습니다.

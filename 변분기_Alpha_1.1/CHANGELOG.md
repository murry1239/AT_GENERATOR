# 개발 이력

## Alpha 1.1 · 2026-10-02

- 문서 앞부분의 첨부자료 목록을 실제 별첨 시작으로 오인하여 본문이 제외되던 범위 판정 수정
- 목차 앞부분과 본문을 함께 비교하고 앞부분 목차들 사이의 일반 번호 첨부자료 목록을 보존
- 표·그림 목차 영어 제목의 단수/복수 형식 인식; 실제 별첨 안의 별도 목차는 앞부분 판정을 확장하지 않음
- 앞부분 첨부자료 목록과 실제 별첨·부록 시작을 구분하는 회귀시험 추가
- schema_version 3 및 기존 scope_policy 유지; 변대생기 Alpha 1.0과의 입력 호환성 유지
- 패키지의 호환용 `version`은 `변분기 Alpha 1.0`, 실제 생성 버전 `producer_version`은 `변분기 Alpha 1.1`로 기록
- 이전 버전을 보존하고 변대생기 Alpha 1.1과 두 폴더로 구성한 통합 ZIP 및 통합 소스 GitHub 업로드 도구 제공

## Alpha 1.0 · 2026-10-02

- Alpha 0.5의 앞부분·본문 비교 및 목차·별첨 제외 규칙 유지
- 화면, 분석 패키지의 생산자 버전, 진단과 배포 파일명을 Alpha 1.0으로 갱신
- 변대생기 Alpha 1.0과 함께 각 한 폴더로 구성한 통합 배포
- schema_version 3 및 기존 scope_policy 유지
- 회귀시험에서 생산자 버전과 패키지 비교 정책도 확인

## Alpha 0.5 · 2026-10-01

- 목차 이전의 문서정보·승인 양식 등 표·문단을 비교 범위에 포함
- 목차 필드/스타일/콘텐츠 컨트롤 및 수동 목차를 비연속 범위로 제외
- 별첨·부록·붙임·첨부·Appendix·Annex 시작 이후 제외
- 표 안 참조 문구는 별첨 시작 경계로 사용하지 않음
- 포함/제외 블록, 문서 앞부분/본문 구분을 schema_version 3 패키지에 기록
- 목차와 비교 대상이 같은 블록에 섞인 경우 전체 제외 및 경고
- 변대생기 Alpha 0.10과의 병합·중첩표 전달 검증; 회귀시험 33개 통과
- 기존 버전을 보존한 새 폴더 및 소스 전용 업로드 BAT 제공

## Alpha 0.4 · 2026-10-01

- 스타일/수준/글자 서식만 다른 블록 및 스타일 의존성에 의한 전체 본문 비교 제외
- run 분할 무시, 내용 공백/줄바꿈·표 병합·그림/링크 대상 변경 보존
- 빈 문단 추가/삭제는 간격 변경으로 제외 (그림/수식/필드 문단은 유지)
- Word Range.EnhMetaFileBits → Pillow PNG 직접 추출, 실패 시 단일 클립보드 대체
- 문서별 연속 3회 그림 추출 실패 시 남은 그림 생략 및 텍스트 보존
- 그림 추출 방식/통계, 전체 분석 소요시간 로그 추가
- 금지 제어문자/긴 텍스트/서식-only/그림 실패/취소 회귀시험
- 업로드된 실문서로 Windows Word 통합시험 수행 (수치와 제한: VALIDATION.md)
- 업무 문서를 제외한 배포 ZIP 생성기 및 소스 전용 GitHub 업로드 BAT/PowerShell 추가
- 기존 Alpha 0.2/0.3 Git 이력 bundle 유지; main 대신 codex/alpha-0.4 브랜치 업로드

## Alpha 0.3 · 2026-09-28

- 변경 전·후 DOCX 2개 필수, 변경이력 DOCX 선택 입력
- DOCX XML 본문 블록 비교 및 임시 복사본 북마크: 전체 승인/거부 복원 생략
- 전후 원문을 기준으로 판단하고 선택 이력 불일치 시 보조 활용 중단
- 양쪽 페이지 번호, 입력 해시, 변경 ID, 단계 소요시간 저장
- 한쪽만 이미지 캡처에 성공해도 해당 이미지는 보존
- 여러 페이지 블록은 잘린 이미지 대신 텍스트와 경고 제공
- Excel 금지 제어문자·길이·수식 오인 처리, 전체 원문 JSON 보존
- 이미지 가로세로 비율 보존, 오래된 클립보드 이미지 재사용 방지
- 취소 버튼, 짧은 오류 안내, 상세 로그, 출력 경로 충돌 방지
- Linux 자동시험 추가. Windows Word 실문서 실행은 사용자 환경에서 확인 필요

# Alpha 1.0 검증 · 2026-10-02

- Alpha 0.5의 비교·범위·캡처 로직을 그대로 유지한 버전 및 배포 정리입니다.
- Word를 열지 않는 회귀시험 33개를 다시 실행하여 통과했습니다. 기존 패키지 생성 시험에서 생산자 버전 `변분기 Alpha 1.0`, schema_version 3 및 scope_policy도 확인합니다.
- 합성 전후 DOCX에서 생성한 Alpha 1.0 .bdsg를 변대생기 Alpha 1.0으로 전달했습니다. 앞부분 병합·중첩표와 본문 변경 2개를 보존하고 목차·별첨 변경을 제외하는 연계 검증을 통과했습니다. 페이지 조회는 모의 객체, 이미지는 텍스트 대체 경로로 확인했습니다.
- Windows PowerShell 5에서 두 폴더의 업로드 준비가 성공했습니다. 명시된 소스 38개와 통합 ZIP만 스테이징되는 것을 확인했습니다.
- 실제 Word 이미지 캡처를 이번 버전에서 새로 수행한 시험은 아닙니다. 아래 Alpha 0.5 검증은 이전 버전에서 확인한 결과입니다.

## Alpha 0.5 검증 · 2026-10-01

- Word를 열지 않는 회귀시험 33개 통과. 이전 내용 비교·캡처·취소 시험과 새 범위 시험 8개를 포함합니다.
- 새 범위 시험: 목차 앞 표 및 본문 변경 포함, 목차/별첨 변경 제외, 수동/필드/콘텐츠 컨트롤 목차, 여러 목차, 표 안 별첨 참조, 깨진 목차 필드, 혼합 블록 경고.
- 실제 보관된 전후 DOCX를 XML 비교한 결과 21개 변경(문단 17개, 표 4개). 이 자료에는 앞부분 변경이 없어 범위 확대에 따른 항목 증가는 없습니다.
- 합성 DOCX의 앞부분 병합·중첩표와 본문을 변경하여 실제 .bdsg와 미리보기 XLSX를 생성하고, 변대생기 0.10으로 DOCX를 생성했습니다. 변경 2개가 전달되고 목차/별첨 변경은 제외되며 표 병합·중첩이 보존되는 것을 확인했습니다.
- 연계 시험의 Word 페이지 조회는 모의 객체를 사용했고 이미지 캡처는 의도적으로 실패시켜 텍스트 대체 경로를 확인했습니다. 이번 버전에서 실제 Word 이미지 캡처를 다시 수행한 시험은 아닙니다.
- 일반 사용자 환경 전체를 보증하는 시험은 아닙니다. 별첨 제목과 목차가 불규칙하거나 같은 표에 섞이면 경고 및 원본 범위를 확인해야 합니다.
- 생성된 합성 대비표를 실제 Microsoft Word에서 읽기 전용으로 열고 PDF 1쪽으로 변환하여 화면을 확인했습니다. 앞부분/본문 행, 변경 표시, 표 내용에 잘림이나 겹침이 없었습니다.

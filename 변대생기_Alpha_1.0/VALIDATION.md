# Alpha 1.0 검증 · 2026-10-02

- 지원하는 Python 3.11에서 회귀시험 13개를 통과했습니다. 기본 입력인 변분기 1.0, 이전 0.5·0.4 패키지 호환, 병합·중첩표, 그림·각주 보존, 검토 저장, 취소 및 입력 검증을 포함합니다.
- Alpha 1.0 변분기가 합성 전후 DOCX에서 생성한 .bdsg를 읽어 최종 DOCX를 생성했습니다. 앞부분의 병합·중첩표와 본문 변경 2개를 포함하고 목차·별첨 변경은 제외하는 연계 검증을 통과했습니다. 페이지 조회는 모의 객체, 이미지는 텍스트 대체 경로로 확인했습니다.
- Windows PowerShell 5에서 두 폴더의 업로드 준비가 성공했습니다. 명시된 소스 38개와 통합 ZIP만 스테이징되는 것을 확인했습니다.
- 이전 0.10의 생성 방식과 레이아웃을 유지한 버전·배포 정리입니다. 실제 Word 렌더링 기록은 아래 이전 버전의 검증과 구분합니다.

## Alpha 0.10 검증 · 2026-10-01

- 회귀시험 12개 통과: 원문/병합·중첩표, 이미지 대체, 검토 병합/제외/저장, 경로/해시/ID 검증, 취소 시 출력 보존, 각주 처리, 이전 0.4 패키지 안내 및 새 비교 정책 검증.
- 변분기 0.5에서 실제 생성한 schema_version 3 .bdsg를 읽어 대비표 DOCX를 생성했습니다. 앞부분 양식 표와 본문 변경 2개가 포함되며 목차/별첨 변경은 제외됩니다.
- 앞부분 표의 병합과 중첩표가 최종 문서 구조에서 보존되는 것을 확인했습니다. 연계 시험의 페이지 조회/이미지 캡처는 모의 처리하였으므로 실제 페이지와 이미지 캡처 품질 검증과 구분해야 합니다.
- 이전 버전의 본문 생성 기능을 유지합니다. 새 비교 범위는 변분기에서 결정하며 기존 0.4 패키지만으로 누락된 앞부분 변경을 복원하지 않습니다.
- 합성 대비표를 실제 Microsoft Word에서 열어 PDF 1쪽으로 변환하고 시각 확인했습니다. 앞부분 표와 본문 행의 배치 및 변경 표시를 확인했습니다.
